# 🧪 IVD 智能故障分析平台

一个基于 Flask 的体外诊断（IVD）设备故障分析系统，支持 SMART 和 VUENS 系列设备的故障诊断和知识库管理。

## ✨ 功能特性

- 🔍 **智能故障分析**：上传日志文件（.txt/.zip），自动识别故障原因
- 📊 **多设备支持**：支持 SMART 系列和 VUENS 系列多种型号
- 📚 **知识库管理**：可视化管理故障规则和解决方案
- 🔄 **版本控制**：完整的规则修改历史和回滚功能
- 🎯 **优先级识别**：自动识别关键故障文件并优先处理
