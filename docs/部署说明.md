```bash

```

### 方式2: 手动部署
```bash
cd /home/ivduser/ivd_deploy

# 构建镜像
docker compose build

# 启动服务
docker compose up -d

# 查看状态
docker compose ps
```

## 📝 常用命令

### 查看日志
```bash
# 所有服务
docker compose logs -f

# 单个服务
docker compose logs -f web
docker compose logs -f worker
docker compose logs -f go-parser
```

### 重启服务
```bash
docker compose restart
docker compose restart web
```

### 停止服务
```bash
./stop.sh
# 或
docker compose down
```

### 进入容器
```bash
docker compose exec web bash
docker compose exec go-parser sh
docker compose exec postgres psql -U ivd_user -d ivd_fault_db
```

## 🐛 故障排查

### 端口被占用
```bash
# 查看端口占用
netstat -tunlp | grep -E '8081|8082|5432|6379'

# 修改端口（编辑docker-compose.yml）
```

### 服务无法启动
```bash
# 查看详细日志
docker compose logs

# 重新构建
docker compose build --no-cache
docker compose up -d
```

### 数据库连接失败
```bash
# 检查PostgreSQL
docker compose exec postgres pg_isready -U ivd_user

# 重启数据库
docker compose restart postgres
```
